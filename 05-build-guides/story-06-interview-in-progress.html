Custom Hook

useTimer Hook Anatomy

Defined at module level, outside the component. Not exported. Returns a formatted string. No useState for the timer — just call the hook.

// Defined at module level in InterviewInProgress.jsx — NOT exported function useTimer() { const [seconds, setSeconds] = useState(0); useEffect(() => { const t = setInterval(() => setSeconds(s => s + 1), 1000); return () => clearInterval(t); // cleanup on unmount — no leak }, []); const h = Math.floor(seconds / 3600); const m = Math.floor((seconds % 3600) / 60); const s = seconds % 60; const pad = n => String(n).padStart(2, '0'); // mm:ss under one hour; hh:mm:ss at one hour or more return h > 0 ? `${pad(h)}:${pad(m)}:${pad(s)}` : `${pad(m)}:${pad(s)}`; } // In the component body — do NOT add useState for timer: const timer = useTimer(); // just a string, e.g. "02:47"
Behaviour Detail
Interval cadenceEvery 1000 ms — one second increments
CleanupclearInterval(t) fires on unmount — no memory leak
Format < 1 hourmm:ss — e.g. 02:47
Format ≥ 1 hourhh:mm:ss — e.g. 1:03:12
PaddingString(n).padStart(2, '0') — always 2 digits minimum
Usage in componentconst timer = useTimer() — a string, not state
