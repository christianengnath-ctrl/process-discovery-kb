Step Indicator

Wizard progress bar

Four steps separated by › characters. The active step has class active. On this screen, Context is active. No other step gets the active class.

Wireframe A — Empty textarea

No content pasted yet

The textarea is empty on first visit (contextBlob is ''). No token chips are shown. Both "Skip for now" and "Continue →" are available — Continue is never disabled.

Wireframe B — Filled textarea

Content pasted — token chips visible

When text.length > 0, two token chips appear below the textarea. The line count is computed from non-blank lines; the token estimate uses Math.round(text.length / 4). "Continue →" is the clear primary action.

Component Anatomy

Timmy + heading row

The avatar and heading sit in a flex row with 16px gap, vertically centred. Timmy is rendered as <Timmy size={56} state="idle" label={false} /> — no label, idle state, 56px size.

Token Chip Behaviour

Conditional rendering

The chip row only mounts when text.length > 0. Clearing the textarea removes both chips from the DOM. Chip 1 counts non-blank lines; Chip 2 estimates tokens at 4 chars per token.

Token formula: Math.round(text.length / 4) — recomputed every render, no memoisation needed.
Line count: text.split('\n').filter(Boolean).length — blank/whitespace lines do not count.
Comma formatting: tokenEst.toLocaleString() — produces "1,234" not "1234" for large numbers.
Navigation Flow

Where each action goes

"Skip for now" and "Continue →" are identical in behaviour — both call handleContinue(). "← Back" goes to / (project list), not back to CreateProject.
