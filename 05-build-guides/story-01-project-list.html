Exists — verify & fix gaps
UI State A — Populated

Project table

The default state. Renders whenever projects.length > 0. Projects are shown in reverse insertion order (newest first).

UI State B — Empty

Empty state

Renders when projects.length === 0. In practice only occurs if the store is cleared — the seed project always exists on first load.

Navigation

Where each action leads

Every click on a row calls setCurrentProject(id) first, then navigates. The "New project" button skips setCurrentProject — no project exists yet.

Data Contract

Project interface

Fields highlighted in blue are used on this screen. All others are stored but not rendered.
