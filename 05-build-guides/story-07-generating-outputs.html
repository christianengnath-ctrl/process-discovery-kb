Wireframes

Screen States — Three Step Snapshots

Steps advance every 800ms automatically. No user action is required at any point. After all 4 steps complete there is a 600ms pause before auto-navigation.

A — Step 0 active (just started)
B — Mid progress (step 2 active)
C — All done (about to navigate)
Timer Logic

Animation Timeline

Total wall-clock time from mount to navigation: 4 × 800ms + 600ms = 3 800ms. A single useEffect([step]) drives the entire sequence.

Step States

Visual State Table

Each step renders one of three visual states based on its index relative to the current step value. The ternary for class and icon must always be in sync.

Implementation

Timer Logic — useEffect([step])

One useEffect, one useState. The effect re-runs every time step changes. Both branches return cleanup functions so no timers leak on unmount.

// STEPS constant — defined at module level, outside the component const STEPS = [ { id: 'flowchart', label: 'Building process flowchart…' }, { id: 'sipoc', label: 'Generating SIPOC table…' }, { id: 'sop', label: 'Writing SOP document…' }, { id: 'transcript', label: 'Transcribing interview…' }, ]; // Inside the component: const [step, setStep] = useState(0); useEffect(() => { if (step < STEPS.length) { const t = setTimeout(() => setStep(s => s + 1), 800); return () => clearTimeout(t); // cleanup if unmounted mid-step } else { const t = setTimeout(() => navigate(`/projects/${id}/outputs`), 600); return () => clearTimeout(t); // cleanup if navigated away } }, [step]); // re-runs every time step increments
// Step list markup — ternary for class and icon must stay in sync: {STEPS.map((s, i) => ( <div key={s.id} className={`generating-step ${i < step ? 'done' : i === step ? 'active' : 'pending'}`}> <span className="generating-step-icon"> {i < step ? '✓' : i === step ? '◌' : '○'} </span> <span className="generating-step-label">{s.label}</span> </div> ))}
